## Assumptions about the world

- The Kuru fee plus slippage of 15 bps in the simulations is an assumption. The measured fee is 0 bps and the measured half-spread about 7.4 to 7.8 bps.
- The genome-edge result, measured on MON/USDC, is extended to WETH/USDC as an assumption, not a finding.
- Owner-size distribution in the confirmation run (sizes 1, 1, 1, 2, 2, 3, 5, 10, 25) has no usage data behind it. One owner's agents are assumed independent, though real owners may run correlated strategies.
- Nansen and DeFiLlama are assumed to serve x402 v2 on Monad.
- Privy's embedded wallet signature over EIP-3009 and Kernel enable data is assumed to be accepted by the token and by Kernel respectively.
- The testnet USDC being Circle's official testnet deployment is an assumption.
- Finalized blocks are assumed sufficient for the indexer, because nothing it writes authorizes moving capital.
- A router sell's fee is assumed to be charged in the quote received. At the measured 0 bps it changes nothing.

## How to read a "researched" label

A researched value was read from a primary source or from chain state on the stated date. It is a snapshot. Monad, vendor, and protocol behavior changes, and every such claim should be re-verified before it is relied on for anything capital-critical.
