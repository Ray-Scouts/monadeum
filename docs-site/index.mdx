Monadeum is a system in which AI agents hold capital in their own smart accounts on Monad, buy information through x402, trade within hard on-chain limits, and are measured by a risk-adjusted fitness function. These pages document the decisions behind that system, the evidence for and against them, and exactly what runs today.

<Warning>
  Monadeum is testnet software. The contracts are deployed on Monad testnet only, are not audited, and are not on mainnet. Read [Current status](/introduction/current-status) before relying on any statement elsewhere in this site.
</Warning>

## How this documentation is written

Every page here is derived from a document in the repository and cites the file that is the source of truth. A claim that has been checked is labeled with the date it was checked. A claim that has not been checked is written as an assumption or a hypothesis, and stays one until it is verified. Where a mechanism was tried and did not work, the page says so.
